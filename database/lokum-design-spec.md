# Lokum App — Design Spec (Product Card + Light/Dark Theme)

## Контекст
Барово меню приложение. Продуктова карта за крафт бира "Гларус", с Light/Dark режим на цялото приложение.

## 1. Layout на продуктовата карта

Хоризонтална карта: снимка вляво (цяла бутилка, без изрязване), информация вдясно.

```
┌─────────────────────────────────────┐
│  ┌────────┐   Гларус                │
│  │        │   Craft IPA · 5.6%      │
│  │ бутилка│                         │
│  │ (цяла) │   Наситен хмелов аромат │
│  │        │   с нотки на цитрус...  │
│  └────────┘   6.50 лв                │
└─────────────────────────────────────┘
```

Ключово: снимката използва `object-fit: contain`, НЕ `cover` — за да се вижда цялата бутилка без изрязване.

```css
.bottle-frame img {
  width: 100%;
  height: 100%;
  object-fit: contain;
}
```

Структура на инфо блока (отгоре надолу):
- **Марка** — bold, най-голям шрифт (~19px)
- **Стил/градус** — по-малък, uppercase, accent цвят (~13px)
- **Описание на вкуса** — muted цвят, по-малък шрифт (~13px)
- **Цена** — bold, accent цвят

## 2. Цветова палитра

### Light mode
| Роля | Цвят | Hex |
|---|---|---|
| Фон | Жълто | `#FBCB3E` |
| Повърхност (карти) | Бяло | `#FFFFFF` |
| Акцент (бутони, надписи) | Лилаво | `#4C1D7C` |
| Акцент 2 (вторичен) | По-светло лилаво | `#6B2FA3` |
| Основен текст | Тъмно лилаво | `#2B0E4A` |
| Приглушен текст | Сиво-лилаво | `#6B5A85` |

### Dark mode
Важно: **не е просто разменени light цветовете**. Тъмен фон + приглушени, не толкова наситени акцентни цветове.

| Роля | Цвят | Hex |
|---|---|---|
| Фон | Тъмно лилаво/почти черно | `#17102B` |
| Повърхност (карти) | По-светло тъмно лилаво | `#241A3D` |
| Акцент (бутони, надписи) | Приглушено златисто-жълто | `#E3B23C` |
| Акцент 2 (вторичен) | По-тъмно златисто | `#C9982E` |
| Основен текст | Светло лилаво-бяло | `#F0E9FF` |
| Приглушен текст | Приглушено лилаво | `#B3A3D9` |

## 3. Техническа реализация (CSS Variables)

```css
:root {
  --bg: #FBCB3E;
  --surface: #FFFFFF;
  --accent: #4C1D7C;
  --accent-2: #6B2FA3;
  --text-main: #2B0E4A;
  --text-muted: #6B5A85;
  --border: rgba(76,29,124,0.15);
}

[data-theme="dark"] {
  --bg: #17102B;
  --surface: #241A3D;
  --accent: #E3B23C;
  --accent-2: #C9982E;
  --text-main: #F0E9FF;
  --text-muted: #B3A3D9;
  --border: rgba(227,178,60,0.2);
}
```

Превключване чрез `data-theme` атрибут на `<html>`, управляван с JS toggle бутон. Препоръка: пази избора в `localStorage`, за да се запомня между сесии.

```js
function toggleTheme() {
  const html = document.documentElement;
  const isDark = html.getAttribute('data-theme') === 'dark';
  html.setAttribute('data-theme', isDark ? 'light' : 'dark');
  localStorage.setItem('lokum-theme', isDark ? 'light' : 'dark');
}

// При зареждане на страницата:
const saved = localStorage.getItem('lokum-theme');
if (saved) document.documentElement.setAttribute('data-theme', saved);
```

## 4. Компоненти, засегнати от темата
- Фон на приложението (`--bg`)
- Меню бутон и категории (chips) — фон `--accent`, текст `--bg`
- Продуктови карти — фон `--surface`
- Заглавия/надписи вътре в картите — `--text-main`
- Toggle бутон за смяна на темата (горе вдясно в topbar-а)
